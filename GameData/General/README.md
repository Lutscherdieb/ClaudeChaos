# General — a Cube Chaos Class mod

A military-themed Class: Strength grows from the sacrifices and reinforcements of the front line. Bomb the enemy from above, shell them from a distance, and drop paratroopers behind their lines.

## Installing this mod (to play it)

1. Find your Cube Chaos install folder (Steam → right-click Cube Chaos → Manage → Browse local files). It's the folder containing `Cube Chaos.exe` and a `GameData/` subfolder.
2. Copy this folder (`GameData/General/`) into `<your Cube Chaos install>/GameData/General/`.
3. Launch the game and enable the Mod.
